# アクセシビリティ確認計画
入力: [requirements.md](../requirements-analysis/requirements.md) NFR4、[stories.md](../user-stories/stories.md)、[team-practices.md](../practices-discovery/team-practices.md)。目標はWCAG 2.1 AAに沿う設計。以下は実装後の確認項目であり合格済みの証拠ではない。

- [ ] lang=ja、見出し順、mainとスキップリンクを備える。
- [ ] 全操作をTab・Enter・Spaceとタブの矢印操作で実行でき、フォーカスが常に見える。
- [ ] ダイアログ内のフォーカス制御、Escape、終了後の復帰を確認する。
- [ ] 通常文字4.5:1以上、大きい文字と操作境界3:1以上のコントラストを実測する。
- [ ] 状態・失敗・選択を色だけで表さず、文章と下線等を併用する。
- [ ] 入力ラベル、単位、エラーの修正方法を示す。エラー要約から該当欄へ移動できる。
- [ ] 320 CSS px・200%・400%拡大で主要操作が欠けず、横スクロールなし。
- [ ] 48pxの操作領域と8px以上の間隔を確認する。
- [ ] 毎秒の残り時間を読み上げ続けず、状態変化・保存・エラーだけ通知する。
- [ ] 未取得・0秒・停止中・完了・古い表示を区別して読み取れる。
- [ ] 0件・1件・10件のベル、長いエラー文、最長180:00を確認する。
- [ ] キーボードとスクリーンリーダーでログイン後の操作を試す。iOS Safari / Android Chromeの対象バージョンは実装計画で確定する。
- [ ] 自動スキャンと手動確認を分けて記録し、未実施は未実施とする。
