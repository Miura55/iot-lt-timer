# 利用者像

入力: [承認済み要件](../requirements-analysis/requirements.md)、[開発方針](../practices-discovery/team-practices.md)、[質問への回答](user-stories-questions.md)。

## P1 主催者

- 役割: 1会場のLTイベントで事前のベル設定と当日の進行操作を行う。優先順位1、唯一のアプリ利用者像。
- 目標: 発表時間に合わせてベルを鳴らし、中断にも対応する。設定を次回の発表に再利用する。
- 困り事: 手動で時計を見続ける負担、端末ごとの時刻差、通信障害時に通知結果が分からないこと。
- 利用場面: PCまたはスマホの日本語画面。少人数の許可済み主催者が同じ会場を操作することがある。
- 技術習熟度: 特定の水準を仮定しない。AWSの設定作業と当日のタイマー操作は手順を分ける。
- 利用頻度: イベント当日の各発表で反復する。週次・月次などの頻度は未確認。

## 関係者

Picoの準備担当は依頼者で、主催者と同一人物でもよい。デバイス証明書やファームウェア、ベル機構の準備は外部連携作業とする。登壇者・観客はアプリ操作の対象ではなく、専用画面や個人情報の収集も初版に含めない。
